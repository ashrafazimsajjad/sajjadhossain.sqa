# Sajjad Hossain — QA Engineer Portfolio

A responsive dark-themed portfolio built with Next.js, JavaScript, Tailwind CSS and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Customize

Edit `components/Portfolio.jsx` to update:
- Name / headline
- Skills
- Projects
- Experience
- GitHub and LinkedIn URLs
- Email

The portfolio's **Download Resume** button serves the redacted CV from:

`public/sajjad_hossain_sqa_resume.pdf`

## Deploy

Push the project to GitHub and import it into Vercel.
